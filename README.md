# Timing the Backward Link in Over-the-Air Split Learning Over an Aging Single-Antenna Channel

This repository reproduces the numerical experiments and figures for a study of backward-link timing, channel aging, and phase correction in over-the-air split learning. All data are generated by the simulations; no third-party datasets or pretrained weights are required.

## Requirements

Python 3.9 or later and a CPU. Install the pinned dependencies with `pip install -r requirements.txt`. The experiments use a single thread per numerical library.

## Reproduction

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
bash run_all.sh quick && bash run_all.sh check && bash run_all.sh paper
bash run_all.sh figures
```

`quick` runs all experiment targets. `check` compares fresh results against the corresponding reference outputs, ignoring intermediate files and execution metadata. `paper` compares reported numbers with fresh output at the paper's printed precision; `bash run_all.sh paper --reference` uses shipped references when fresh outputs are unavailable. The documented discrepancy makes `paper` return a nonzero status. Run the figure command separately, as shown above, after `quick`.

The figures command regenerates its E1–E3 CSV inputs from the fresh per-run results and writes `figures/fig1_lobes.pdf` and `figures/fig2_deadzone.pdf`. Reference CSVs, including E4 for the numerical table checks, are retained in `reference_results/figures/` for reference-only checks. The E1–E4 gate decision is a shipped input, not recomputed by these targets.

## Known discrepancy

The paper prints a maximum of 2.12 jackknife standard errors, while the code gives 2.114, which rounds to 2.11 at the printed precision.
